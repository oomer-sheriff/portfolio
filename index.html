YouTube Agentic System

An end-to-end distributed agentic system that transforms YouTube videos into structured summaries. It decouples the Reasoning Engine (LLM) from data processing using the Model Context Protocol (MCP) and handles heavy tasks via async orchestration.

  • Microservices Architecture: Decoupled Backend, AI Workers, and MCP Server.
  • Async Orchestration: RabbitMQ & Celery for non-blocking transcription & inference.
  • Cloud-Native: Containerized with Docker, deployable on Kubernetes.
  • Optimized caching: Redis for vector embeddings & response caching.
